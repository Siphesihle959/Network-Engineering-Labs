## Home Network Setup and Wireless Router Configuration

#### Objective (What will be achieved)

Configure a home network by connecting devices, configuring a wireless router, enabling DHCP and Wi-Fi, and verifying internet connectivity for wired and wireless clients.


#### Devices Used (Added/Configured)

* Cable Splitter
* Cable Modem
* Home Wireless Router
* Office PC
* Bedroom PC
* Laptop
* TV


#### IP Addressing (Focus on what I configured)

* Configured **Office PC** to obtain an IP address via **DHCP**.
* Configured **Bedroom PC** to obtain an IP address via **DHCP**.
* Verified the **Laptop** received an IP address via DHCP after connecting to the wireless network.
* Reduced the router DHCP pool to **10 users**.


#### Steps Performed

* Connected the cable splitter to the cable modem and TV using coaxial cables.
* Connected the cable modem to the wireless router.
* Connected the Office PC and Bedroom PC to the router using Ethernet cables.
* Accessed the router's web interface using the default gateway.
* Changed the router administrator password.
* Configured the DHCP server to support a maximum of 10 users.
* Enabled the 2.4 GHz wireless network.
* Changed the SSID to **MyHome**.
* Configured **WPA2-Personal** wireless security.
* Set the wireless passphrase.
* Connected the laptop to the wireless network.


#### Test Results

* Verified the TV received cable service.
* Verified the Office PC accessed the router GUI.
* Verified the Laptop successfully connected to the Wi-Fi network.
* Verified the Office PC, Bedroom PC, and Laptop successfully accessed **skillsforall.srv**.
* Confirmed internet connectivity for both wired and wireless devices.
