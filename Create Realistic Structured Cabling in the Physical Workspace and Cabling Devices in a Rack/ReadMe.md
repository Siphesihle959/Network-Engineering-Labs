# Patch Panel and Wall Mount Installation Documentation

## Objective

Install a patch panel and wall mounts, then connect office network devices through structured cabling.


## Devices Used

* Patch Panel0
* Office-SW1 Switch
* Copper Wall Mount(s)
* Copper Straight-Through Cables


## IP Addressing

* No IP addressing configuration performed in this exercise.


## Steps Performed

* Installed Patch Panel0 in the equipment cabinet rack.
* Connected Office-SW1 GigabitEthernet ports to corresponding patch panel jacks.
* Installed a wall mount in the office.
* Connected the wall mount to the patch panel using structured cabling.
* Added and connected an additional wall mount.
* Verified all cabling connections between the office and wiring closet.


## Test Results

* Patch panel successfully installed in the rack.
* Switch ports successfully connected to patch panel jacks.
* Wall mounts successfully connected to the structured cabling system.
* Physical network connections completed without errors.


## Skills Demonstrated

* Structured cabling installation
* Patch panel deployment
* Wall mount installation
* Switch-to-patch-panel connectivity
* Cable management
* Physical network infrastructure setup


## Key Concepts Learned

* Purpose of a patch panel in network infrastructure.
* Relationship between wall mounts, patch panels, and switches.
* Structured cabling best practices.
* Centralized cable management in a wiring closet.
* Physical layer connectivity in a LAN.


## Conclusion

Successfully installed and connected a patch panel and wall mounts, creating an organized structured cabling system between office devices and the wiring closet.
