# Wireless, Bluetooth, and Cellular Connectivity Documentation

## Objective

Connect devices using WLAN, Bluetooth, and cellular tethering technologies to enable wireless network communication.


## Devices Used

* Laptop
* User-Laptop
* Smartphone
* Office Tablet
* Bluetooth Speaker
* Wireless Module (WPC300N)


## IP Addressing

* Laptop received an IP address automatically from the Office WLAN.
* Smartphone received an IP address from the cellular network.
* User-Laptop received an IP address through Bluetooth tethering from the Smartphone.


## Steps Performed

* Removed the Ethernet module from the Laptop.
* Installed the WPC300N wireless adapter.
* Connected the Laptop to the **Employee** WLAN using the provided pre-shared key.
* Verified wireless connectivity through a web browser.
* Enabled Bluetooth on the Office Tablet and Bluetooth Speaker.
* Discovered and paired the Bluetooth Speaker with the Office Tablet.
* Tested the Bluetooth connection using the Music Player.
* Enabled Bluetooth and cellular tethering on the Smartphone.
* Enabled Bluetooth on the User-Laptop.
* Paired the Smartphone with the User-Laptop.
* Tethered the User-Laptop to the Smartphone via Bluetooth.
* Verified internet access through the tethered connection.


## Test Results

* Laptop successfully connected to the Employee WLAN.
* Laptop successfully accessed **office.srv**.
* Bluetooth Speaker successfully paired with the Office Tablet.
* Audio playback successfully transmitted through Bluetooth.
* User-Laptop successfully obtained an IP address via tethering.
* User-Laptop successfully accessed **office.srv** through the cellular network.


## Skills Demonstrated

* Wireless network configuration
* WLAN authentication
* Wireless adapter installation
* Bluetooth pairing
* Bluetooth device management
* Cellular tethering
* Connectivity verification
* IP address verification


## Key Concepts Learned

* Installing and configuring wireless network adapters.
* Connecting devices to a WLAN using an SSID and pre-shared key.
* Bluetooth discovery, pairing, and communication.
* Smartphone cellular network connectivity.
* Bluetooth tethering for internet access.
* Dynamic IP address assignment over wireless networks.


## Conclusion

Successfully connected devices using Wi-Fi, Bluetooth, and cellular technologies. Verified network access, Bluetooth communication, and internet connectivity through smartphone tethering, demonstrating practical wireless networking skills.
